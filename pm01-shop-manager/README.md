# Northstar Shop Desk

Локальное desktop-приложение для каталога товаров, заказов и управления ассортиментом. Интерфейс работает на Tkinter, данные сохраняются в SQLite; браузер и сервер не нужны. Исходные CSV и полный перечень полей к заданию в рабочей папке не были приложены, поэтому при первом запуске создаётся демонстрационный магазин техники. Его можно заменить импортом подготовленного CSV.

## Основные возможности

- Вход с проверкой логина и пароля из БД; пароли хранятся через PBKDF2-HMAC-SHA256.
- Гостевой вход с просмотром каталога без инструментов фильтрации.
- Роли продавца, менеджера и администратора с разными наборами действий.
- Каталог в виде карточек: поиск по названию/описанию, сортировка, фильтр категории и «Только в наличии».
- Визуальные метки новинок, цифровых товаров и уценки; отсутствующая обложка заменяется заглушкой.
- Заказы с ФИО и контактами клиента, суммой, составом, статусом и сроком доставки. Просроченные заказы подсвечены.
- Администратор может добавлять, редактировать и удалять товары, загружать обложки до 2 МБ и импортировать каталог из CSV.
- Удаление товара блокируется, если товар уже присутствует в заказах.

## Стек

Python 3.10+, Tkinter, SQLite, Pillow. Внешний сервер БД не требуется. CairoSVG нужен только для пересборки диаграмм (`pip install -r requirements-docs.txt`).

## Структура проекта

```text
app/                   интерфейс, авторизация, БД и запросы
database/schema.sql    схема SQLite и ограничения
database/*.csv         шаблон импорта каталога
docs/                  user story, модель данных, ER и блок-схема PDF/SVG
tests/                 автоматические проверки
assets/uploads/        обложки, загруженные администратором
data/shop.db           создаётся при первом запуске
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `SHOP_DB_PATH` | Путь к файлу SQLite | `data/shop.db` внутри проекта |

## Запуск

1. Установите Python 3.10 или новее и Pillow (`python -m pip install -r requirements.txt`).
2. Запустите `run.bat` или командой `python -m app.main` из корня проекта.
3. При первом запуске создаётся БД и демонстрационные записи.

Для проверок выполните `python -m pytest`. Схему отдельно можно выполнить в SQLite из файла `database/schema.sql`.

### Демо-учётные записи

| Роль | Логин | Пароль |
|---|---|---|
| Продавец | `seller` | `seller123` |
| Менеджер | `manager` | `manager123` |
| Администратор | `admin` | `admin123` |

Это локальные демонстрационные пароли. Для реального использования замените их до передачи базы другим пользователям.

### Импорт каталога

Откройте приложение как администратор → «Импорт CSV». Шаблон с заголовками и категориями находится в `database/products_template.csv`. Кодировка — UTF-8; обязательные поля: `name, description, category, price, stock, is_digital, is_new, is_slow_moving`. Логические значения: `true/false`, `1/0` или `да/нет`. Импорт выполняется одной транзакцией: ошибочная строка не оставит в БД частично загруженные товары.
