# Алгоритм авторизации

`auth-flow-gost.svg` и `auth-flow-gost.pdf` показывают алгоритм входа по ГОСТ 19.701-90: начало/завершение, ручной ввод, действия и решения обозначены разными фигурами; ветви подписаны «Да» и «Нет».

Хэш пароля сравнивается через PBKDF2-HMAC-SHA256 и constant-time `compare_digest`. Гость получает отдельную сессию без учётной записи. После успешного входа главная форма строится с учётом роли.
